# Image Semantic Communication with Enhanced Low-SNR Robustness
基于深度学习的图像语义通信系统：低信噪比场景下的鲁棒性增强与性能优化

---

## 项目概述
本项目在现有图像语义通信论文模型的基础上，通过引入多尺度注意力（MSA）增强模块、渐进监督机制与语义增强策略，显著提升了低信噪比环境下的图像重建质量。在 BPSK@-18dB 条件下，模型 PSNR 指标从基线的 12.95dB 提升至 17.50dB，实现了 4.55dB 的性能增益，在 Set14/BSD100 数据集上验证了改进方案的有效性与泛化能力。

## 技术栈
- Python 3.x
- PyTorch
- 深度学习（CNN / 注意力机制）
- 语义通信（联合编码调制）
- 图像重建与评估（PSNR / SSIM / LPIPS / FID）

## 核心改进与亮点 ✨
1. **多尺度注意力增强模块（MSA）**
   针对低信噪比环境下的语义信息丢失问题，设计多尺度注意力增强模块，强化关键特征提取能力，提升模型对噪声干扰的鲁棒性。

2. **渐进监督与语义增强机制**
   通过多阶段渐进式监督训练与语义信息增强策略，引导模型在极端信道条件下优先保留关键语义特征，有效缓解噪声对重建质量的影响。

3. **多调制方式对比实验**
   搭建 BPSK/4QAM/16QAM/64QAM 多调制方式实验环境，覆盖 -18dB ~ 18dB 全信噪比场景，完成模型性能的全面对比与消融实验。

4. **全维度量化评估**
   基于 PSNR/SSIM/MS-SSIM/LPIPS/FID/CR 等多维度指标，对模型重建质量、感知一致性与计算复杂度进行综合评估，验证改进方案的性能增益。


## 实验结果（关键指标）
| 调制方式 | 信噪比 (dB) | 基线PSNR (dB) | 改进后PSNR (dB) | 性能提升 |
| :--- | :--- | :--- | :--- | :--- |
| BPSK | -18 | 12.95 | 17.50 | +4.55 dB |
| BPSK | 0 | 23.10 | 25.80 | +2.70 dB |
| 4QAM | -10 | 18.20 | 21.30 | +3.10 dB |
